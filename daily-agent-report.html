Daily Agent Report

An automated performance report for an outbound/inbound call floor. Every rate is judged against a “frontier” benchmark — the 70th percentile of real clean-day performance for that campaign × call-type over ~30 days — so a hard campaign or a short shift is never unfairly penalised. Pace, closing and a combined index; per-dialler breakdowns; break-pattern and work-from-home detection; and a historical awards engine. Rebuilt from the original Excel/Sheets model.

All agent names, campaigns, diallers and figures are invented for this recreation. No employer or client data appears on this page. Structure, metrics and logic mirror the original.
